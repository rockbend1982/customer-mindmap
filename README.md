# 人脈圖（customer-mindmap）

個人客戶關係心智圖。單檔網頁 App，手機優先，**資料只存在裝置的瀏覽器本機儲存，不上傳任何伺服器**。程式碼公開（GitHub Pages 部署用），但程式裡不含任何客戶資料。

## 功能（v1）

- 客戶建檔：姓名、電話、公司／職業、怎麼認識的、標籤、熟度（鐵桿／溫／冷）、備註
- 關係圖：資料自動生成節點與連線，熟度上色；點節點看詳情、拖節點排版（位置會記住）、雙指縮放、單指平移、搜尋定位
- 關係種類：介紹人（有方向、箭頭）、家人、朋友、同事、同社團＋可自訂
- 互動紀錄：每次聯絡記一筆（日期＋內容），首頁顯示最近 10 筆
- 標籤與熟度篩選、全文搜尋
- 備份：一鍵匯出 JSON（iPhone 走分享面板存 iCloud Drive）；超過 7 天未備份，首頁紅字提醒；可匯入備份還原（整份取代）

## 使用方式（iPhone）

1. Safari 開啟部署網址
2. 分享按鈕 →「加入主畫面」
3. **之後固定從主畫面圖示開啟**（主畫面版與 Safari 分頁的儲存空間是分開的，混用會看到兩份不同資料）

## 資料邊界（重要）

- 手機＝唯一正本，只在手機上編輯
- Mac 或其他裝置要看資料：匯入最近的 iCloud 備份檔（唯讀參考用，不要兩邊同時編輯，會互相蓋掉）
- 換手機／重灌：在新裝置開啟 App → 設定 → 匯入備份

## 開發

純 vanilla HTML/CSS/JS 單檔（`index.html`），無任何第三方依賴。本地測試：

```bash
python3 -m http.server 8080
```

## v2 已完成（2026-08-27）

- 視覺：Nu Skin 極簡黑白 / 暖紙感雙主題切換，熟度色、關係線色、名稱全可自訂
- 關係圖：聚焦模式（第二層展開）、圖上篩選、多重關係弧線、連線種類標籤
- 沉睡視覺化：超門檻天數節點變淡＋首頁「該聯絡了」名單（門檻可調）
- 首頁「網絡洞察」：樞紐人物、轉介發動機、孤島客戶、該回溫的鐵桿
- 轉介鏈樹狀圖：只看誰介紹誰的族譜視角
